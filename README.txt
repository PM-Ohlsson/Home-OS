HOME OS v0.5 — design prototype

Open index.html in a browser. No server required.
The clock is live; weather, Plejd scenes and Polestar values are demos.

Visual customization:
- Smooth gradients: edit CSS .hero, .scenes, .forecast and .car in index.html.
- Grain is OFF by default. Open Settings in the dashboard to test its opacity.
- Replace assets/grain.png with your own transparent texture (PNG).
- assets/polestar-top.svg is a stylized, editable vector illustration, not an official Polestar image.

Forecast dots and weekday columns share 10%, 30%, 50%, 70%, 90% centers.
Designed for landscape tablet display, with a mobile fallback.
